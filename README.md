# Transformaciones2D
; Registro de nubes de puntos 2D con PSO se buscan los parámetros de la transformación que lleva con  un .csv a una nube transformada, minimizando el error en coordenadas homogéneas. Cuatro experimentos (rígida, similar, afín, homografía) con animación, y uno final que une dos fotos en un mosaico con OpenCV.
